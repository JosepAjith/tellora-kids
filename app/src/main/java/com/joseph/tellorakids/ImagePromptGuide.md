## 🛠 Pro Tips for the Developer
1.  **Consistency**: Use the same "Style Suffix" for every single image generation.
2.  **Format**: Download as PNG/JPG, then use [Squoosh.app](https://squoosh.app/) to convert to **WebP** and resize to **1280x720**.
3.  **Naming**: Save them exactly as named above (e.g., `moon_1.webp`) into `app/src/main/assets/images/`.
