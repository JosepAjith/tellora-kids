# 🎨 Tellora Kids: Premium AI Image Generation Guide

To maintain a world-class, Disney-inspired aesthetic that looks perfect on both phones and tablets, use these optimized parameters in **Microsoft Designer (Bing)**, **Leonardo.ai**, or **Midjourney**.

## 🌟 The "Universal Magic" Style Suffix
**Add this to the end of EVERY prompt for style consistency:**

`3D digital illustration, Pixar and Disney inspired style, soft cinematic lighting, vibrant pastel colors, cute expressive characters, high-detail textures, magical storybook aesthetic, clean whimsical background, centered composition, main character in middle, 4:3 aspect ratio, 8k resolution`

--

## 🛠 Principal Architect's Production Tips
1.  **Aspect Ratio**: ALWAYS use **3:4**. This ensures the image fills the 60% hero area on phones and 50% on tablets without any parts being cropped.
2.  **Composition**: ALWAYS use **centered composition**. The main character should be in the middle of the frame. This prevents the "Model Overlap" text card from covering important parts of the character.
3.  **Resolution**: Download at the highest quality, then use [Squoosh.app](https://squoosh.app/) to resize to exactly **1536 x 2048 px**.
4.  **Format**: Convert to **WebP (Lossy)** at 75-80% quality. This keeps the app size small (under 300KB per image) while keeping Pixar-level detail.
5.  **Safe Zone**: Keep the main characters/action in the **center 60%** of the frame (horizontally and vertically) to account for the UI overlays and "Model Overlap" effect.
6.  **Naming**: Save exactly as named above (e.g., `hippo_cover.webp`) into `app/src/main/assets/images/`.
