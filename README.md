# Tellora Kids: A World of Stories for Kids

Tellora Kids is a premium children's storytelling platform designed for safe, engaging, and educational reading experiences for children aged 2–12.

## ✨ Features
- **Curated Stories:** Beautifully crafted stories by professional storytellers.
- **Child-Safe UI:** Magical, Pixar-inspired design with soft rounded corners and intuitive navigation.
- **Offline Reading:** Download stories and read them anywhere.
- **Parental Gate:** Secure parental controls for settings and purchases.
- **Premium Experience:** Ad-free reading with a subscription.

## 🛠 Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Architecture:** MVVM + Clean Architecture
- **Dependency Injection:** Hilt
- **Database:** Room (Offline-first)
- **Networking:** Retrofit + OkHttp
- **Reactive Programming:** Coroutines + Flow
- **Cloud:** Firebase (Authentication, Firestore, Storage, Analytics, Crashlytics)
